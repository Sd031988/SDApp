# Pibo 3D – echte Katzengeräusche und Lizenzen

Für die realistischere Spielwelt werden **nur bei eingeschaltetem Ton und einer entsprechenden Spielaktion** (zum Beispiel Streicheln oder Spielen) zwei echte Katzenaufnahmen von **Wikimedia Commons** nachgeladen:

1. **Miauen** – „Maullido de gata hembra joven.ogg“, Urheber: **George Miquilena**, Aufnahme einer jungen Katze, **Creative Commons CC0 1.0** (gemeinfrei gewidmet). Original und Lizenz: https://commons.wikimedia.org/wiki/File:Maullido_de_gata_hembra_joven.ogg
2. **Schnurren** – „Whiskers' purr.ogg“, Urheber: **Adam Cuerden**, reale Hauskatze beim Streicheln, vom Urheber **Public Domain** freigegeben. Original und Lizenz: https://commons.wikimedia.org/wiki/File:Whiskers%27_purr.ogg

Die Audioquelle wird bei aktiver Wiedergabe direkt vom Wikimedia-Commons-Server angefordert. Dabei kann dieser Server technisch notwendige Verbindungsdaten (z. B. IP-Adresse) erhalten. Es findet **keine** Audioübertragung an ChatGPT, den SD Hub oder Werbenetzwerke statt. Kein Mikrofonzugriff ist für Katzengeräusche nötig.

Falls die Originalaufnahmen nicht geladen werden können (z. B. offline, Browser sperrt Format oder Drittanbieter), verwendet Pibo weiterhin die im Projekt selbst erzeugten Geräusche. Fressen, Wasser, Schlafen, Spülen und andere Effekte bleiben aus dem selbst entwickelten WebAudio-Generator und sind keine echten Tonaufnahmen.

Ton ist per Schalter ausstellbar, Lautstärke bleibt lokal gespeichert. Das automatische Abspielen von Medien vor einer Nutzeraktion ist unterbunden. Für eine später vollständig offline nutzbare Version sollten die gemeinfreien Aufnahmen lokal im Repository abgelegt werden, statt sie vom externen Anbieter abzurufen.
