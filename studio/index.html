SD Code-Studio · KI-Werkstatt

✨ Mit KI programmieren

Ohne API-Schlüssel: ChatGPT oder Gemini in einem neuen Tab verwenden. Das Studio sendet keine Projektdateien automatisch an diese Dienste. Eine echte KI-Unterhaltung direkt hier erfordert eine autorisierte Integration.

Wähle die Dateien aus, die ChatGPT/Gemini für diese Änderung verstehen muss. Der bisherige Code wird nur nach deiner ausdrücklichen Zustimmung in die kopierte Anfrage aufgenommen. Andere Projektdateien bleiben unverändert.

🔗 ChatGPT direkt verbinden – ohne API

Mit der freiwilligen Chrome-Erweiterung kannst du eine Antwort in ChatGPT oder Gemini markieren, per Rechtsklick an das Studio senden und hier sicher prüfen.

SD Code-Studio · Google KI

✨ Google KI nutzen

Du brauchst kein zusätzliches SD-Code-Studio-Konto. Probiere Google KI zuerst ohne Registrierung aus.

Wichtig: Einige Google-KI-Funktionen lassen sich ohne Google-Anmeldung nutzen. Das hängt jedoch von Land, Gerät und Funktion ab. Fordert Google eine Anmeldung, kann SD Code-Studio sie nicht umgehen. Google KI läuft auf Googles Webseite, nicht in einem eingebauten Chat des Studios.

Code ins SD Code-Studio übernehmen

Google KI-Antwort kopieren → „KI-Code einfügen“ → Dateien erkennen und prüfen → ausgewählte Dateien übernehmen. Bestehende Dateien werden vor Änderungen gesichert.

Kopiere die gesamte KI-Antwort auf einmal, auch wenn Erklärungen davor oder dazwischen stehen. Das Studio filtert die Erklärungen heraus und übernimmt nur erkannte Codeblöcke. HTML, CSS, JavaScript, Python, Java, C/C++, C#, TypeScript, Rust, Go und weitere Sprachen werden getrennten Dateien zugeordnet.

🛡 Automatische Codeprüfung

🔧 Reparaturassistent

Einfache, eindeutig begrenzte Korrekturen werden als Code-Vergleich vorbereitet. Komplexe Probleme erhalten eine sichere Reparaturanfrage. Nichts wird automatisch gespeichert oder ausgeführt.

Korrekturen werden nur vorgeschlagen und nie automatisch gespeichert.

Prüfergebnis: vor und nach der Reparatur

Noch keine lokalen Tests ausgeführt.

    Hier laufen echte, begrenzte statische Prüfregeln (z. B. JSON, Sicherheitsbefunde und lokale Dateiverknüpfungen). Dein HTML, JavaScript oder Python wird dabei nicht gestartet. Für Laufzeittests wäre eine zusätzliche isolierte Umgebung erforderlich.

    Nur statische, lokale Prüfregeln. Kein KI-Modell, keine ausgeführten Tests und keine Garantie auf Fehlerfreiheit. Hinweise betreffen überwiegend geänderte Zeilen; mögliche Zugangsdaten werden in den gesamten ausgewählten Dateien gesucht.
