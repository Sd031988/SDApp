🔗 ChatGPT-Antwort direkt ins SD Code-Studio bringen

Mit deinem bestehenden ChatGPT-Konto, ohne API-Schlüssel und ohne Zugriff auf andere private Chats. Du bestimmst selbst, welchen Text du überträgst.

1. Kostenlose Chrome-Erweiterung herunterladen

Die Erweiterung fügt in ChatGPT und Google Gemini beim Markieren von Text eine Rechtsklick-Aktion hinzu. Sie liest nur den Text, den du selbst markiert und ausdrücklich zum Senden ausgewählt hast.

Die ZIP wird aus drei öffentlichen Dateien direkt in deinem Browser zusammengestellt. Sie enthält keine Kontodaten oder Passwörter.

Windows 10/11: Python-Assistent für Edge & Chrome

Der Windows-Script-Host-Fehler 800A03EA entsteht beim direkten Öffnen von studio-bridge.js. Diese Datei ist für die Browser-Erweiterung bestimmt. Unser Windows-Paket enthält die korrekte Installation und einen Python-Einrichtungsassistenten.

Mit Windows 10/11 und Edge oder Chrome. Python 3.9+ nur für den Assistenten erforderlich; die Erweiterung kann auch ohne Python geladen werden.

2. Erweiterung einmalig in Chrome einrichten

  1. ZIP entpacken – du bekommst einen Ordner mit manifest.json, background.js und studio-bridge.js.
  2. In Chrome chrome://extensions öffnen.
  3. Entwicklermodus einschalten und Entpackte Erweiterung laden wählen.
  4. Den entpackten Ordner auswählen.

Diese Variante wird lokal installiert und ist derzeit keine im Chrome Web Store veröffentlichte Erweiterung. Prüfe die Berechtigungen vor der Installation.

3. Antwort mit einem Klick ins Studio übertragen

  1. ChatGPT öffnen und dich in deinem eigenen Konto anmelden, falls nötig.
  2. Die gewünschte ChatGPT-Antwort oder einen Codeabschnitt markieren.
  3. Rechtsklick → Ausgewählten KI-Text an SD Code-Studio senden.
  4. Das Studio öffnet sich. Es erkennt HTML, CSS, JavaScript und andere Dateien. Vergleiche die Änderungen und übernimm die gewünschten Dateien erst nach deiner Freigabe.

Datenschutz: Keine automatische Anmeldung, kein Zugriff auf ChatGPT-Passwörter oder Cookies, kein heimliches Lesen deines Chatverlaufs. Die Auswahl wird nur kurz im Sitzungsspeicher deiner Chrome-Erweiterung gehalten und nicht an unseren Server hochgeladen.

Ohne Erweiterung

Du kannst weiterhin in ChatGPT auf Kopieren klicken und im SD Code-Studio unter ✨ KI Coding → Gesamte KI-Antwort einfügen den vollständigen Text einfügen.
