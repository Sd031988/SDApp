Anleitung – SD Bewerbungsstudio starten

Am einfachsten: direkt im Browser

Du brauchst nichts herunterzuladen oder zu installieren. Öffne einfach thesdhub.com und wähle unter "Bereiche" die gewünschte App (Bewerbung, PDF Studio, Scanner oder Passfoto). Alles läuft direkt im Browser, deine Daten bleiben auf deinem Gerät.

Auf dem Handy kannst du die App zusätzlich über "Zum Home-Bildschirm hinzufügen" (iPhone) bzw. "App installieren" (Android) wie eine normale App auf deinem Startbildschirm ablegen.

Downloads für Windows, macOS und Linux

Wer die App lieber lokal ohne Internetverbindung nutzen möchte, findet auf der Startseite unter "Downloads" passende Pakete:

DateiFür wen?
Windows ZIPWindows-Nutzer, PowerShell-Start mit automatischem Browser-Öffnen
macOS ZIPMac-Nutzer, Startskript mit Python 3
Linux ZIPLinux-Nutzer, lokales Startskript

Windows – Schritt für Schritt

  1. ZIP-Datei entpacken
  2. Enthaltene Datei doppelklicken – die App öffnet sich automatisch im Standardbrowser
  3. Falls Windows eine Sicherheitswarnung zeigt: auf "Trotzdem ausführen" klicken

macOS – Schritt für Schritt

  1. ZIP-Datei entpacken
  2. Enthaltenes Startskript öffnen (bei Bedarf im Finder mit Rechtsklick → "Öffnen", falls macOS zunächst warnt)
  3. Die App öffnet sich im Standardbrowser

Linux – Schritt für Schritt

  1. ZIP-Datei entpacken
  2. Startskript im Terminal ausführbar machen und starten
  3. Die App öffnet sich im Standardbrowser

Systemvoraussetzungen

  • Windows 10 oder höher, macOS 11 oder höher, bzw. eine aktuelle Linux-Distribution
  • Ein aktueller Browser (Chrome, Firefox, Edge oder Safari)
  • Internetverbindung nur beim allerersten Start nötig (danach auch offline nutzbar)
